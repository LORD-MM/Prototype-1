# Prototype 1: Driving Game

A simple 3D driving game from Unity's **Junior Programmer** pathway (Create with Code). You drive a vehicle down a road and steer around obstacles, with the camera following from above and behind.

- **Controls:** W/S to drive forward and back, A/D to turn
- **Challenge 1:** a bonus scene where you fly a plane forward and tilt it up and down with the arrow keys

## Details
- **Unity version:** Unity 6.6 (6000.6.0f1)
- **Input:** New Input System (main prototype)
- **Scenes:** `Assets/Scenes/Prototype 1.unity`, `Assets/Challenge 1/Challenge 1.unity`
